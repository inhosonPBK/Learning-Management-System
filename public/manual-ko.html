01 · 시작하기

계정은 사전에 등록되어 있습니다 — 별도 가입 없이 로그인하세요

모든 사용자

첫 로그인

  1. People Operations로부터 임시 비밀번호를 Teams DM으로 받습니다.
  2. 사이트에 접속해 회사 이메일과 임시 비밀번호로 로그인합니다.
  3. 바로 비밀번호 변경 화면이 열립니다. 새 비밀번호(10자 이상, 영문+숫자)를 두 번 입력하고 비밀번호 변경을 누르세요.
  4. 대시보드로 이동하면 준비 완료입니다.
비밀번호를 잊으셨나요? 셀프 재설정 메일은 발송되지 않습니다. People Operations 또는 관리자에게 임시 비밀번호 재발급을 요청하세요. 재발급 후 첫 로그인 시 다시 변경하게 됩니다.

언어 전환

상단 우측 🌐 KO 버튼으로 한국어/English를 전환할 수 있습니다. 선택은 계정에 저장됩니다. 정부 제출용 면담일지 출력물은 항상 한글로 표시됩니다.

비밀번호 변경 · 로그아웃

우측 상단 이니셜 아바타를 누르면 비밀번호 변경, 관리(권한자만), 로그아웃 메뉴가 열립니다.

03 · 피교육자

인턴 · 신입 · 경력 OJT — 주간 교육 보고서 작성

Trainee

내 교육 확인

대시보드 내 교육 카드에 프로그램명, 멘토, 현재 주차, 진행률이 표시됩니다. 카드 이름을 누르면 직무기술서(JD)와 교육계획(현재 주차 구간이 노란색으로 강조)을 볼 수 있습니다.

주간보고서 작성

  1. 카드의 📄 주간보고서 → 주차 그리드에서 작성할 주차를 클릭합니다. 현재 주차는 노란 테두리로 표시됩니다.
  2. 상단 이번 주 주제를 입력합니다 (예: "생산 라인 실습 시작").
  3. 세 섹션을 채웁니다: 01 이번 주 배운 것 · 02 이번 주는 어땠나요(평점 선택 + 소감) · 03 질문 & 더 알고 싶은 것
  4. 입력 내용은 자동 저장됩니다 ("저장됨 ✓"). 언제든 나가도 초안이 유지됩니다.
  5. 완성되면 제출 →. 주제가 비어 있으면 확인 창이 뜹니다.
제출 후 수정하려면멘토가 리뷰를 완료하기 전이라면 회수하여 수정으로 초안으로 되돌릴 수 있습니다.
멘토 피드백 확인제출 후 하단 04 멘토 피드백에 잘한 점·다음 주 집중·Q&A·진행 상태가 표시됩니다.
완료된 보고서리뷰가 완료되면 잠기며 🖨 출력으로 PDF 저장이 가능합니다.
면담보고서는 멘토·매니저가 작성하는 관리 기록으로, 피교육자 화면에는 표시되지 않습니다.

04 · 멘토

주간보고서 리뷰 · 면담보고서 작성 · 정부양식 면담일지 출력

Mentor · Co-mentor

리뷰 대기 확인

대시보드 처리 필요에 멘티가 제출한 보고서가 리뷰 대기로 나열됩니다. 항목을 누르면 바로 해당 주차로 이동합니다. 내 멘티 카드에도 대기 건수 배지가 표시됩니다.

주간보고서 리뷰

  1. 피교육자가 작성한 01~03 섹션을 읽습니다 (읽기 전용).
  2. 04 멘토 피드백에 이번 주 잘한 점 · 다음 주 집중 사항 · Q&A 요약을 입력합니다. 입력란을 벗어나면 자동 저장됩니다.
  3. 진행 상태를 선택합니다: 정상 진행 / 소폭 조정 / 점검 필요 (필수)
  4. ✓ 리뷰 완료 → 보고서가 완료로 잠깁니다.
리뷰 완료 후에는 피교육자도 멘토도 수정할 수 없습니다. 재오픈이 필요하면 People Operations 또는 관리자에게 요청하세요.

면담보고서 작성

  1. 멘티 카드의 💬 면담보고서 → + 새 면담보고서
  2. 면담일을 선택하고 면담내용 및 청년 건의사항을 한 칸에 작성합니다. (안내 틀: 면담내용 / 건의 및 문의 / 조치사항 / 기타)
  3. 자동 저장 후 제출 →. 제출한 보고서는 수정하기로 회수·수정하거나 삭제할 수 있습니다.

면담일지 출력 (청년친화강소기업 정부양식)

면담보고서 목록 또는 멘티 카드의 🖨 면담일지 출력을 누르면 연번 · 성명 · 근무부서 · 면담일 · 면담내용 및 청년 건의사항 5컬럼 표가 새 창에 열립니다. 제출된 보고서만 포함되며, 근무부서는 팀의 한글명으로 표기됩니다. 우측 하단 버튼으로 인쇄/PDF 저장하세요.

05 · 매니저 · People Operations · GM

열람 범위와 권한

Read · Oversight
역할열람 범위추가 권한
직속 매니저내 직속 팀원의 제출된 주간·면담보고서 (내 팀 섹션)팀원 대상 면담보고서 작성 · 면담일지 출력
추가 열람자 (관리자가 지정)지정된 피교육자의 보고서공동 멘토로 지정되면 리뷰 가능
People Operations전사 모든 제출 보고서 (전사 현황)프로그램·등록·멘토 배정·팀명 관리, 완료 보고서 재오픈
GM전사 모든 제출 보고서읽기 전용
매니저 열람 범위는 직속 1단계입니다. 상위 디렉터가 특정 피교육자를 봐야 하면 관리자가 추가 열람자로 지정합니다. 작성 중인 초안은 작성자 본인 외 누구도 볼 수 없습니다.

보고서 메뉴에서 열람 가능한 모든 피교육자 카드를 확인하고, 카드 이름 → JD·교육계획·주차 현황·면담 목록을 볼 수 있습니다.

06 · 관리자

관리 메뉴 — Admin · People Operations

Admin · People Ops

교육 프로그램 만들기 (People Ops · Admin)

  1. 관리 → 프로그램 우측 폼에서 유형(인턴십 / 신입 OJT / 경력 OJT), 한글·영문명, 시작·종료일을 입력합니다. 기간(주)은 비워두면 자동 계산됩니다.
  2. 사용 보고서(주간 / 교육훈련 / 면담)를 체크하고 상태를 진행 중으로 두면 바로 사용됩니다.

피교육자 등록 · 멘토 배정

  1. 프로그램 상세 우측 피교육자 등록: 피교육자, 멘토, JD, 교육계획을 입력합니다.
  2. 교육계획은 한 줄에 하나: 주차 | 주제 | 방법 | 담당 — 예: 1-2 | 온보딩 & 안전교육 | OJT | 멘토
  3. 등록 후 각 카드에서 멘토 변경, 상태(진행 중/완료/중단), 개별 시작·종료일, 추가 열람자(열람자 / 공동 멘토)를 관리합니다.

사용자 관리 (Admin)

사용자 추가입사자 프로필 + 로그인 생성. 임시 비밀번호가 1회 표시되니 즉시 Teams DM으로 전달하세요.
임시 비밀번호 재발급비밀번호 분실 시. 기존 비밀번호는 즉시 무효화되고 다음 로그인에 변경을 강제합니다.
비활성화 / 재활성화퇴사자는 비활성화 — 로그인 차단, 멘토 배정 해제, 프로필·보고서는 보존. 복귀 시 재활성화.
권한 플래그Admin · People Operations · GM. 매니저·멘토 권한은 조직도와 등록에서 자동 파생됩니다.

팀 · 감사 로그

팀: 10개 팀의 한글/영문명과 팀 리드를 수정합니다. 한글명은 정부양식 근무부서에 그대로 인쇄됩니다. 감사 로그(Admin): 로그인, 제출, 리뷰 완료, 사용자·등록 변경 등 최근 200건.

데이터는 매주 월요일 0시(KST) GitHub Actions로 자동 CSV 백업되며 90일간 보관됩니다.

07 · 자주 묻는 질문

제출했는데 수정하고 싶어요

주간보고서: 멘토 리뷰 완료 전이면 회수하여 수정. 완료 후에는 People Ops/관리자에게 재오픈 요청. 면담보고서: 수정하기로 회수 후 수정, 또는 삭제 후 재작성.

멘티 카드가 보이지 않아요

관리자가 해당 등록에 나를 멘토(또는 공동 멘토)로 배정해야 표시됩니다. 직속 팀원이면 내 팀 섹션에 나타납니다.

주차는 어떻게 계산되나요?

프로그램(또는 개별) 시작일 기준 월요일~목요일 단위로 1주차부터 셉니다. 그리드의 주차 라벨에 날짜 범위가 표시됩니다.

모바일에서도 쓸 수 있나요?

네. 좌측 상단 ☰ 메뉴에서 이동하며, 모든 폼과 그리드는 모바일 폭에 맞춰 재배치됩니다.
